# Folder Aset Gambar XI RPL

Taruh foto-foto Anda di dalam folder ini (`assets/images/`) sesuai dengan nama file yang dirujuk pada file `index.html`:

## Daftar File Gambar yang Digunakan:
1. **Logo Sekolah**: `assets/images/logo-sekolah.png` (Rekomendasi ukuran: Square / 200x200px PNG transparan)
2. **Hero Banner / Background**: `assets/images/hero-bg.jpg` (Rekomendasi ukuran: 1920x1080px)
3. **Galeri Kelas**:
   - `assets/images/galeri-1.jpg` (Praktikum Lab)
   - `assets/images/galeri-2.jpg` (Project Showcase)
   - `assets/images/galeri-3.jpg` (Kebersamaan Kelas)
   - `assets/images/galeri-4.jpg` (Event & Lomba)
   - `assets/images/galeri-5.jpg` (Coding Workshop)
   - `assets/images/galeri-6.jpg` (Kunjungan Industri)
4. **Foto Guru & Wali Kelas**:
   - `assets/images/guru-wali.jpg` (Foto Wali Kelas)
   - `assets/images/guru-1.jpg` (Guru Pemrograman Web)
   - `assets/images/guru-2.jpg` (Guru Pemrograman Berorientasi Objek)
   - `assets/images/guru-3.jpg` (Guru Basis Data)
5. **Kegiatan Kelas**:
   - `assets/images/kegiatan-1.jpg`
   - `assets/images/kegiatan-2.jpg`
   - `assets/images/kegiatan-3.jpg`
6. **Foto Murid / Siswa XI PPLG (9 Murid)**:
   - Buat sub-folder `siswa/` di dalam `assets/images/`
   - Simpan foto ke-9 murid dengan nama: `siswa-1.jpg` sampai `siswa-9.jpg` (Rekomendasi rasio 1:1 Pasfoto/Square).
